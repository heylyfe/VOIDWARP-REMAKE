## What was built

1. `game/sim/enemy_runtime.gd` (sim layer, pure/deterministic):
   - `EnemyBehavior` base (on_spawn / tick / on_vote; DESIGN.md section 12 contract, extension via
     `preload(...).EnemyBehavior` - no global class_name anywhere, per the headless rule);
   - per-enemy rng: a Mulberry32 stream per enemy row, derived from the run's `enemy_ai` stream
     seed (D-T010-3) mixed with spawn order - two enemies never share a stream state (asserted);
   - the D-056 spawn rule: tick 360 (6.0 s; Early Bird = opts 120); fallback (a) preferred kind
     anchor -> (b) lane anchor -> (c) any round-trip tile >= 25 u from the spawn point; never
     within 25 u of the player; farthest-from-the-player first; within-60 u preference at (a)/(b)
     only (dropped at (c)); tie-break lowest anchor index ((a)/(b)) / lowest tile index ((c));
     copies >= 30 u apart (SR-3), plan order, deterministic on identical inputs (asserted). If no
     candidate exists, the spawn defers to the next tick (D-T027-4). Step (c)'s round-trip set is
     rebuilt from the level dict with voidgen's own `movement()`/`bfs()` (D-T027-3);
   - vote counts: `add_vote(id, max_votes)` (per-id numbers stay in content enemy.json);
   - overtime multipliers: +6% speed / -5% cooldowns per tier 0..8, every 20 s after beacon open
     (period a parameter - Long Night 14 s / Cold Blood 30 s work through the same knob), SR-5
     `clamp_pursuit` helper, SR-1 never-multiplied vertical easing in `move_toward`;
   - telegraph events (`api.telegraph(kind, shape, ticks)`), projectiles (`api.spawn_projectile`,
     kill on hit, tile/prop collision, safe-tile mirror into `w["projectiles"]`);
   - `api.los` tile/prop ray (0.25 u march, D-T027-2 [CONTESTABLE]);
   - the KILL API: `api.kill(player, killer_id)`, `api.push(player, dir, speed)`,
     `api.lock_abilities(player, ticks)` - routed into the T-012 controller (`try_kill`,
     velocity set, `apply_lock`); suppression (respawn / Last Light) stays the controller's call.
     There is no partial-effect call; the framework checks every body contact itself, and
     `contact_kill: false` is the only opt-out (thicc ben) (D-T027-5).
2. `game/view/billboard.gd` (view layer): manual Y-billboard (rotation around world up every
   frame; testable facing), alpha-scissor 0.5, nearest filter, frame animation from sprites.json
   (T-016 schema), scale so the BODY is `world_height` u tall with its body bottom on the origin,
   and the diegetic spawn text (`spawn_text`, D-T027-7 [CONTESTABLE]).
3. The hit cylinder: `cylinder_from_sheet` - diameter = 0.8 x body width, height = body height,
   derived per frame from `body_rect`; the PNG frame size never enters the shape (D-T027-6).
4. Diegetic spawn text: the `enemy_spawn` event carries the display name as `text`.
5. Tests (run() -> Array[String], discovered by run_all.gd, no class_name, preload only):
   - `tests/test_hitbox.gd` - A7: probes inside the PNG rect (side/corner/top/bottom padding)
     never hit; inside-body probes do; frame size invariance; live contact through a full runtime.
   - `tests/test_billboard.gd` - normal . camera forward <= -0.999 from 8 angles (45 deg apart);
     Y-only facing for an off-axis camera; material (alpha-scissor 0.5, nearest); frame advance/
     loop/scale from the real kiwi_cat TBD sprites.json.
   - `tests/test_kill_api.gd` - body contact kills (code `D-TBD`, killer name on the event); a
     push never kills; respawn invulnerability suppresses the kill (event `kill_suppressed`) and
     the contact kills once it runs out; locks are tick-denominated and expire exactly; EVERY
     fixture here has Last Light already spent via its own save path (D-057).
   - `tests/test_spawn_rule.gd` (extra, deliverable 1 is a rule - it gets proof): fallback order,
     25 u floor, 60 u window dropped at (c), determinism + tie-break, votes, SR-3 copy
     separation through the full 361-tick spawn path, diegetic text content.
