## 4. NEW DECISIONS ENTRIES (DECISIONS.md, end of section B2)

- D-T082-1 [CONTESTABLE] — Third-person orbit camera: pivot 2.5 u above the feet, radius
  7.0 u sphere, offset = R_y(yaw)·R_x(pitch)·(0,0,7.0), look target = pivot; default pitch

  jump-buffer window, so a step-up never delays an input reaction).

  (left stick move, A/X/Y); JUMP and INTERACT are held bits (hold-to-confirm tally is
  altar-view logic; variable-jump cut is the controller reading the bit over time); Tab/Esc
  are app-level flags outside the wire format; move vector normalized to magnitude <= 1,
  rotated by camera yaw, scaled by 127, rounded to int8; exactness statement pinning the
  test tolerances; capture() is a pure function with no engine Input singleton.
- D-T082-3 [CONTESTABLE] — user://settings.json fields/ranges from the T-024 addendum;
  chosen failure behavior: clamp-or-default on load, settings can never fail to boot;
  path parameterized so tests never clobber the real file.
