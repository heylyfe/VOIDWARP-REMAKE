## Decisions (full list in DECISIONS.md, D-T041-1..5)

- D-T041-1: the fade-in window is 15-25 u, bounds inclusive; ties break to the
  lowest tile index (the same determinism convention D-056's step (c) uses).
- D-T041-2: the platform-tile-only filter is data-only on this sim surface:
  the API's tile rows carry no platform/walkway bit, so the filter is the
  distance window + the spawn-hub fallback (the farthest tile within 12.0 u of
  the level's first `open` anchor). Flagged for T-073 like the toucher's
  live-tile surface.
- D-T041-3: the dais cell is cut out of the marked patch when the player
  stands dais-adjacent; the dais cell itself is never inside the lethal column.
- D-T041-4: the void zone's column kill and the fade-back lift are row state
  (row["patch"]); the boundary tick (738) closes the zone FIRST and THEN lifts
  - a fade-back tick is never a kill tick.
- D-T041-5: the strike cooldown is row arithmetic - 840 base, -180 per extra
  vote, floored at 300 - counted from the fade-back's end, so the "14 s"
  number a player acts on is the wait between the end of one footprint and the
  start of the next mark.
